# Persistent rules

- `references/source_documents/` is immutable, primary candidate evidence.
- `profile/master_profile.yaml` is a reviewed derivative, never independent evidence.
- Preserve evidence in `profile/evidence_index.yaml`; every material claim needs source provenance or an explicit later user-approved fact.
- Cover letters are factual and voice evidence. Ingest the complete recursive corpus, not only the latest CV.
- Never invent skills, proficiency, years, metrics, publications, responsibility, direct experience, or language ability. Treat uncertain and conflicting facts as unavailable.
- Use concise, technically precise, restrained writing. Tailor by selecting, ordering, and accurately phrasing verified evidence.
- Normal runs never edit templates. Validate structured data, audit facts, compile LaTeX, and test PDF text extraction. Stop on failures.
- Stop at document generation: the user reviews and submits applications manually.
